# Prompt Engineering Workflow

## Prompt 1
Generate an SEO blog outline for a cafe targeting students and remote workers.

## Prompt 2
Write a long-form SEO blog based on the outline.

## Prompt 3
Create a content cluster strategy with supporting articles and target keywords.

## Prompt 4
Generate internal linking suggestions for SEO optimization.

## Prompt Engineering Insights

- Structured prompts produced better blog organization.
- SEO-specific instructions improved keyword relevance.
- Content clusters enhanced topic authority.
- Internal linking improved content strategy.

## Learning Outcome

This project demonstrates how AI can be used to generate SEO-friendly content and content marketing strategies through prompt engineering.
